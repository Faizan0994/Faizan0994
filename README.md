# 💫 About Me:
Full-stack AI engineer and automation architect with hands-on experience building web and mobile products, AI agents, and the automations around them. I build the system, then let the busywork run itself.

I build agents of all kinds, retrieval systems, computer vision and image processing pipelines, and workflow automations that retry, recover, and alert on their own. Alongside that, I research deep learning and neural networks, with a focus on how models actually work under the hood.

On the engineering side, I work across MERN, Spring Boot, and ASP.NET Core, build mobile apps with React Native, and go lower level in C++, C#, and x86 assembly when a problem needs it. Day to day I use Python, TypeScript, PostgreSQL, Docker, and Linux.

Computer engineering student at UET Lahore, comfortable on both sides of the hardware line. I build systems that read raw sensor signals, filter and classify them, and drive physical actuators in real time, from microcontroller firmware to serial communication to the software layer on top.
